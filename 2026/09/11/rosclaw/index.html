RosClaw：自然语言控制 ROS2 机器人

项目定位：让机器人不再需要写死指令，而是通过消息 App 用自然语言直接控制 ROS2 机器人。用户在 Telegram / WhatsApp / Discord / Slack 里发一句话，AI Agent 把它翻译成 ROS2 的 topic 发布、service 调用或 action goal，机器人执行后把反馈流式回传到聊天窗口。

工作链路

  1. 用户在任意消息 App 发送自然语言指令
  2. OpenClaw 的 AI Agent 收到消息，调用 RosClaw 插件注册的 ROS2 工具
  3. Agent 把意图翻译成 ROS2 操作（topic publish / service call / action goal）
  4. 机器人执行，Agent 把反馈流式回传到聊天窗口

核心模块

  • @rosclaw/openclaw-plugin：核心扩展，提供 tools / hooks / skills / commands
  • @rosclaw/rosbridge-client：独立的 TypeScript rosbridge WebSocket 客户端
  • @rosclaw/openclaw-canvas：实时机器人 dashboard（Phase 3）
  • rosclaw_discovery：ROS2 Python 节点，能力自动发现（CapabilityManifest）
  • rosclaw_msgs：自定义消息与服务定义（GetCapabilities）

Agent 工具集

AI Agent 可以调用的 ROS2 工具：

工具 说明
ros2_publish 向任意 topic 发布消息
ros2_subscribe_once 读取某个 topic 的最新一条消息
ros2_service_call 调用 ROS2 service
ros2_action_goal 发送带反馈的 action goal（Phase 2）
ros2_param_get/set 读写节点参数
ros2_list_topics 发现可用 topic
ros2_camera_snapshot 抓取相机帧

传输层与安全

  • 三种传输层：local（进程内）、rosbridge（WebSocket）、WebRTC（低延迟点对点）
  • 安全验证器：safety/validator.ts 对命令做校验，约束 Agent 的操作边界
  • 紧急停止：/estop 命令绕过 AI 直接急停
  • 技能（skills）：check-status、navigate-to、pick-object、take-photo 等封装好的复用能力

示例

  • turtlebot-chat：给 TurtleBot 发「前进 1 米」「去厨房」「看看你在看什么」等指令
  • fleet-patrol：多机编队巡逻
  • arm-control：机械臂控制

技术栈

ROS2 · TypeScript · OpenClaw · rosbridge · WebRTC · Nav2 / MoveIt2 · Docker · pnpm monorepo

仓库：ROSAgent
