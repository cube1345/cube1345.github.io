这是这个博客的第一篇正式示例文章。

这次搭建主要做了几件事：

- 调整了站点标题、副标题和首页节奏
- 补齐了关于、友链、分类、标签等基础页面
- 优化了导航、卡片和内容区的视觉样式
- 为后续 GitHub Pages / GitHub Actions 部署预留了结构

## 为什么先保留这篇文章

保留这篇文章的目的不是充当最终内容，而是作为一个站点样式示例，用来观察这些东西在页面上的显示效果：

- 首页文章卡片
- 分类页归档效果
- 标签页聚合效果
- 文章页头图、目录和元信息
- 侧栏中的最近文章与站点信息

## 目前这篇文章承担的作用

你可以先重点看下面几个入口：

1. 首页是否能正确显示封面、摘要和元信息
2. 分类页里 `博客搭建` 这个分类是否出现
3. 标签页里 `Hexo`、`Butterfly`、`GitHub Pages` 是否出现
4. 文章页里的封面、标题和内容区样式是否自然

## 后续计划

等站点结构稳定后，这篇文章可以继续扩展成真正的博客搭建记录，例如补充：

- 目录结构说明
- GitHub Actions 部署流程
- 主题参数修改经验
- 内容组织和页面设计思路

## 小结

如果现在分类、标签和首页文章卡片都能正常展示，说明这个博客已经脱离默认初始化状态，开始具备继续写内容的基础了。
